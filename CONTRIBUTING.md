# Contributing

Thank you for improving this set. Open an issue describing the financial concept, where the icon would appear, and how it differs from existing icons before drawing a new one.

- Draw an original, brand-neutral symbol on a 24 × 24 viewBox.
- Use `fill="none"`, `stroke="currentColor"`, `stroke-width="1.8"`, rounded caps and joins.
- Keep paths simple; avoid raster images, text, logos, external references, and scripts.
- Check recognition at both 24 px and 16 px, on light and dark backgrounds.
- Add English and Arabic labels to `icons.json` and a row to the README.
- Run `python3 scripts/validate.py`, review `preview/index.html`, and attach before/after visuals if changing an existing icon.

Pull requests should address a real issue or improve usability, documentation, accessibility, or an existing icon. Split independent improvements only when each is useful on its own.
